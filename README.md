# 🏦 Banking Management System

Welcome to the Banking Management System!

This is a Java-based console application that allows users to register, log in, create bank accounts, and perform basic banking operations using a MySQL database.

## 🚀 Getting Started

Follow these steps to set up and run the project on your local machine.

### 1. Clone the Repository

```bash
git clone https://github.com/YourUsername/Banking-Management-System.git
2. Set Up the Database
Create a MySQL database named:
banking_system
Then execute the SQL script available in the database/ folder to create the required tables.
3. Configure Database Connection
Update the MySQL username and password in the Java code according to your local MySQL configuration.
4. Run the Application
Open the project in IntelliJ IDEA and run:
BankingApp.java
